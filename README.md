# Kaïna — Challenge IA « Le manager augmenté »

Données fictives créées pour l'atelier Challenge IA.

- `landing/` : landing page du salon Hanout Expo (stand B12), méthode AIDA, un seul bouton « Être rappelé par un pré-vendeur » (demande envoyée par WhatsApp).
- `parc/` : application de gestion du parc automobile, version autonome. Les données sont enregistrées dans le navigateur de chaque utilisateur ; boutons Sauvegarder / Restaurer (.json).

## Mise en ligne avec GitHub Pages
Settings › Pages › Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
Le site est ensuite disponible sur `https://belamriamina-cpu.github.io/kaina/`.
